## 🚀 GitHub Pages-এ লাইভ করার সহজ নিয়ম (How to Live on github.io)

### পদ্ধতি ১: গিট কমান্ড দিয়ে (Git CLI)

আপনার টার্মিনালে নিচের কমান্ডগুলো রান করুন:

```bash
git init
git add .
git commit -m "Update education institutions and biodata"
git branch -M main
git remote add origin https://github.com/Mahmudul07-prog/Bio_Data.git
git push -u origin main
```

এরপর:
1. GitHub-এ আপনার রিপোজিটরির **Settings**-এ যান।
2. বাম পাশের মেনু থেকে **Pages** অপশনে ক্লিক করুন।
3. **Branch** অংশে `main` সিলেক্ট করে **Save** দিন।
4. ১-২ মিনিটের মধ্যে আপনার বায়োডাটা লাইভ হয়ে যাবে:
   👉 `https://mahmudul07-prog.github.io/Bio_Data/`

---

### পদ্ধতি ২: সরাসরি GitHub ওয়েবসাইটে ফাইল আপলোড করে

1. [GitHub](https://github.com)-এ গিয়ে একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: `biodata` বা `profile`).
2. `index.html` ফাইল এবং `assets` ফোল্ডারটি (ভিতরের ছবিসহ) আপলোড করে Commit করুন।
3. **Settings > Pages > Branch: main > Save** সিলেক্ট করলেই আপনার লাইভ লিঙ্ক পেয়ে যাবেন!
